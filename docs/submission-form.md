# 제출 폼 텍스트 초안 (원티드 AI Championship 2026)

## 서비스명
RE:RUN — 스스로 고치는 업무 자동화

## 해결하려는 문제
비개발 실무자가 만든 업무 자동화는 예외 입력을 만나 조용히 깨지는 순간 버려집니다.
자유 서식 이력서 한 장에 스크리닝 자동화가 멈추면, 고칠 줄 모르는 실무자는 수작업으로
돌아가고 자동화 투자는 사라집니다. 문제는 자동화를 "만드는 것"이 아니라
"깨졌을 때 스스로 회복하는 것"입니다.

## AI 활용 방식
① 자연어 한 문장을 실행 가능한 워크플로우로 변환(계획 생성)
② 단계별 출력에 데이터 계약(zod 스키마) 검증을 걸어 실패를 자동 감지
③ 실패 시 AI가 해당 단계의 설정·입력·오류를 분석해 근본 원인과 수정안(프롬프트 diff)을 실시간 생성
④ 수정안은 사람 승인 게이트를 통과해야만 적용 — AI 자율 수정 차단, 전 과정 타임스탬프 감사 로그 기록
⑤ HR 이력서 스크리닝 템플릿으로 실증: 자유 서식 이력서로 인한 실패(매 실행 100% 재현)를
   진단→승인→재실행으로 복구, 규칙 기반이 탈락시킬 뻔한 지원자를 정상 평가

## 사용한 AI 도구
- OpenAI GPT-4.1 mini (서비스 런타임: 워크플로우 계획·구조화 추출·자가진단·매칭 평가)
- Claude Code / Claude Fable 5 (개발 도구: 설계·구현·테스트 전 과정)
